# Hiking Website

A database-driven hiking retail website developed using PHP, MySQL, JavaScript, HTML and CSS.

The project demonstrates server-side web development, relational database integration and user authentication.

## Technologies

- PHP
- MySQL
- JavaScript
- HTML
- CSS

## Features

- User registration and login
- Database-backed user accounts
- Product/content pages
- User dashboard
- Server-side PHP functionality
- MySQL database integration

## Local Setup

1. Clone the repository.
2. Create a MySQL database.
3. Copy 'config.example.php' to 'config.php'.
4. Enter local database credentials in 'config.php'.
5. Run the site through a PHP-compatible local server.

'config.php' is ignored by Git and should not be comitted.

This project developed my understanding of full-stack web development, PHP server-side programming,
